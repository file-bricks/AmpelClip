# AmpelClip Support

## Deutsch

Support-Kanal für öffentliche Builds:

- GitHub Issues: <https://github.com/file-bricks/AmpelClip/issues>
- Sicherheitsmeldungen: siehe `SECURITY.md`

Bitte niemals echte Zwischenablageinhalte, personenbezogene Daten, IBANs, Telefonnummern, E-Mail-Adressen, Kundendaten oder interne Dokumentauszüge in öffentliche Issues kopieren. Für Fehlerberichte reichen nachgestellte Beispieldaten, Screenshots ohne sensible Inhalte und eine kurze Beschreibung von Windows-Version, Ampel-Modus und aktivierten Mustern.

AmpelClip ist ein lokaler Datenschutz-Helfer. Es gibt keine Garantie auf vollständige Anonymisierung; Ergebnisse müssen vor der Weitergabe sensibler Texte geprüft werden.

## English

Support channel for public builds:

- GitHub Issues: <https://github.com/file-bricks/AmpelClip/issues>
- Security reports: see `SECURITY.md`

Never paste real clipboard content, personal data, IBANs, phone numbers, email addresses, customer data or internal document excerpts into public issues. Use synthetic examples, screenshots without sensitive content and a short description of Windows version, traffic-light mode and enabled patterns.

AmpelClip is a local privacy helper. It does not guarantee complete anonymization; results must be reviewed before sharing sensitive text.
